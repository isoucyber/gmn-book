## GMN BOOK OFFLINE — Fase 1 (núcleo da biblioteca)

**Downloads**
- `GMN-BOOK-Setup-*-x64.exe` — instalador para Windows 10/11 (64 bits).
- `GMN-BOOK-*.apk` — instalação direta em Android.
- `GMN-BOOK-*.aab` — pacote para publicação na Google Play.
- `SHA256SUMS.txt` — conferência de integridade dos arquivos.

Cada instalação tem o seu próprio banco de dados local e criptografado. Não há sincronização automática entre aparelhos: use **Backup e restauração** para transferir dados.

Veja o manual em `docs/MANUAL.md` e o estado do projeto em `PROJECT_STATUS.md`.
